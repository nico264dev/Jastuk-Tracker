# Jastuk Tracker

Electron dashboard for the Jastuk Tracker local telemetry API.

This repository is now focused on the desktop UI only. The Electron app connects to a local tracker API at `http://127.0.0.1:48251` and displays live job telemetry, history, raw JSON, and Discord configuration.

## Quick start

From the repository root:

```powershell
npm install
npm start
```

## Package

To build a Windows installer or packaged app:

```powershell
npm run dist
```

## Publish updates

The in-app updater checks GitHub releases for `nico264dev/Jastuk-Tracker`. Increase the `version` in `package.json`, then publish a GitHub release with the files generated by `npm run dist`, including the installer and `latest.yml`.

For direct publishing through electron-builder, set a GitHub token with release permissions and run:

```powershell
$env:GH_TOKEN="your_github_token"
npm run dist -- --publish always
```

## Usage

- The app launches a modern desktop dashboard.
- The tracker backend must be available on `127.0.0.1:48251`.
- Use the Account tab to store `DISCORD_CLIENT_ID` and `DISCORD_CLIENT_SECRET` in each user's local `.env` file.
- Use the Account tab to check for and install app updates after installing a packaged release.

## User data and releases

Packaged releases store login users and job history in Electron's per-user app data folder. Do not ship local `electron/users.json`, `electron/jobs.json`, or `.env` files with a release build. The build config excludes those files so every person who installs the app has to sign in with their own Discord account.

Keep private API tokens in each user's local `.env` file. Do not hardcode Hub bearer tokens into the Electron source because they can be extracted from a shared installer.

Discord login uses the bundled public `electron/app-config.json` values by default. `DISCORD_CLIENT_SECRET` is optional for installed users; when it is empty, the app uses Discord's browser OAuth token flow and still checks the required guild role.

## Shared live map

Every driver can see their own local telemetry because it comes from `127.0.0.1`. To let everyone see everyone else, you need a central live API. Configure these values in `.env` or bundled app config:

- `LIVE_PUSH_URL` — endpoint that receives the current user's normalized live driver payload by `POST`.
- `LIVE_DRIVERS_URL` — endpoint that returns all currently online drivers by `GET`.
- `DRIVER_USERS_TOKEN` — optional bearer token used for both live endpoints.

Without a central push/fetch API, each installed app can only see its own local tracker data.

## Discord Rich Presence

The app updates Discord Rich Presence from local telemetry when Discord is running. Upload `public/img/logo.png` to your Discord application Rich Presence assets with the key `logo`. For truck brand icons, upload assets using keys such as `brand_man`, `brand_scania`, `brand_volvo`, `brand_daf`, `brand_mercedes_benz`, `brand_iveco`, `brand_renault`, `brand_freightliner`, `brand_kenworth`, `brand_peterbilt`, `brand_international`, `brand_mack`, and `brand_western_star`.
